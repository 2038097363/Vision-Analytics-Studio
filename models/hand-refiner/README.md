# 独立手部局部修复

该目录只保存版本、来源、许可证与验收口径，不会在生成时自动联网下载权重。

手部修复使用 `runtime/hand-refiner/.venv` 独立环境，不能向现有
`runtime/tryon/.venv` 安装旧版依赖。当前实现使用本地 SD 1.5 Inpainting，只在某一侧
手部核验失败时裁剪局部区域并生成四个候选。候选必须重新通过左右手关键点、自然细节、
手长、同位置肤色、手机保护和服装完整性检查；没有候选通过时保留服装阶段的原结果。

RTX 5060 Laptop 8GB 的单样例端到端验证已通过：模型约 2.14 GB，四候选生成约 24 秒，
峰值显存约 2677 MiB。该状态只代表开发机单样例可用；商店发布前仍需完成 20 张固定集、
组合许可证和干净机器安装验收。
