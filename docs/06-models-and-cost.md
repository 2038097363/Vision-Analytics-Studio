# 模型、免费 API 与成本控制规划

> 规划基线：2026-09-14。面向 Windows 桌面软件；本地优先、云能力可选。本文核对了公开官方文档，未登录账号核对个人余额，未调用模型、上传用户图片或测试实际网络连通性。免费政策、模型上下线和账号权益会变化，发布前必须再次核验。

## 1. 推荐决策

**先用现有电脑完成本地闭环，再增加一个用户自带密钥的免费视觉理解入口。** 国内候选优先评测智谱 BigModel 的免费视觉模型；百炼用于有期限的试用对照；Gemini 留作支持地区用户的可选项；SiliconFlow 当前不作为已确认的免费视觉默认源。

“免费 API”只减少部分模型调用费用，不能代替本地试衣算力、科学测量、文件管理，也不能保证长期为全部商店用户提供服务。第一版默认不充值、不购买调用套餐、不绑定自动付费路线。

### 三种运行方式

| 方式 | 图片去向与密钥 | 成本与适用范围 |
| --- | --- | --- |
| 本地模式，默认 | 图片和推理留在用户自己的电脑 | 无 API 账单；仍有电费、存储和时间成本 |
| 自带密钥 BYOK，可选 | 用户电脑直接请求选定服务商；密钥留在系统安全存储 | 使用用户自己的免费层/试用额度；耗尽回退 |
| 平台体验额度，后续 | 开发者密钥只在辅助服务器；图片经明确授权后转发 | 必须有应用账户/会话配额、全局熔断和服务商上限；零预算阶段不面向公众开放 |

商店用户默认使用自己的设备。开发者的 RTX 5060 Laptop 约 8GB 显存、16GB 内存仅用于开发和小规模验证，不是所有用户共享的免费 GPU。未来 4 核／2GB 服务器可做账户、配置与受限代理，不能承担扩散试衣或通用视觉大模型推理。

## 2. 哪些任务值得用 API

| 模块 | 本地负责的主流程 | 可选视觉 API 的位置 | API 不能代替的结果 |
| --- | --- | --- | --- |
| 虚拟穿搭 | 姿态/掩膜、试衣生成、保存、对比 | 衣服类别和可见颜色建议；公开服装图描述；用户主动请求的搭配说明 | 指定衣服准确上身、真人身份保持、尺码/合身度保证 |
| 植物与农业 | 图片质检、本地候选、资料检索与观察档案 | 普通植物图的候选复核、可见特征描述、补拍建议 | 可靠物种真值、病因确诊、生产用药决策 |
| 实验室 | 原始位深读取、分割、校准、人工修订、确定性统计 | 用户授权的非敏感示例说明；从已算好的统计表生成文字摘要 | 像素级分割真值、精确数量/尺寸、异常比例与病理判断 |
| 个人相册 | 导入、哈希、缩略图、标签、向量检索 | 用户选中非敏感图片的标签建议或说明 | 全相册默认上云、可靠人物身份识别、自动删除判断 |

相册本地基线已接入 MobileNetV3 Small ImageNet-1K 权重：权重约 9.8MiB，当前机器实测走 CUDA；首版只接受最高类别概率至少 35% 且能映射到用户已启用安全类别的结果，其余留在未分类。权重 URL、大小和 SHA-256 记录在 `models/album/manifest.json`，商店版在许可复核前采用用户按需下载与校验，不直接打进安装包。该基线用于验证本地任务闭环，后续仍需用真实授权相册评测阈值和类别覆盖。

纯文本解释优先使用模板或已有结构化结果，避免为了生成两句话上传原图。通用 VLM 的自然语言计数不进入实验室统计表；其猜测不写成已确认标签。

## 3. 免费视觉 API 候选核验

以下“可用”指公开文档确认存在该能力，不代表当前账号已开通或本机已经实测。均在 2026-09-14 核验。

### 3.1 智谱 BigModel：国内免费视觉首选候选

- 官方 `GLM-4.6V-Flash` 页面明确为免费版本，支持图像、视频、文本、文件输入，输出文本；`GLM-4V-Flash` 也有免费图像理解定位。先评测前者，后者仅作为轻任务备选。[GLM-4.6V-Flash](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)、[GLM-4V-Flash](https://docs.bigmodel.cn/cn/guide/models/free/glm-4v-flash)
- 这是 API 模型能力，不要求购买 Coding Plan 才能视为免费。只准许明确的免费模型 ID；名称含 `FlashX` 或去掉 `Flash` 的其他版本不可自动替换。模型定价以实际型号为准。[模型总览](https://docs.bigmodel.cn/cn/guide/start/model-overview)
- 额度不是无限并发：官方按账户权益、模型与负载限制并发，存在高峰限流和平台过载。本文不编造固定每日免费张数，接入时以账号控制台为准。[速率限制](https://docs.bigmodel.cn/cn/api/rate-limit)
- 国内平台作为国内用户候选；官方 FAQ 当前表示 API 调用不强制实名认证，但实际注册、账号校验、地域可用性仍需实测。不能把国内平台与海外 Z.ai 套餐视为相同产品。[实名认证 FAQ](https://docs.bigmodel.cn/cn/faq/authentication-issues)
- 数据条款不支持宣传“免费 API 完全不训练、不留存”：隐私政策涉及匿名数据用于算法训练，境内运营个人信息境内存储；留存按必要期限及法定要求处理。[隐私政策](https://docs.bigmodel.cn/cn/terms/privacy-policy)
- 用户协议允许调整免费服务目录、范围与频率，并对利用输出训练其他模型设有限制。软件使用其结果展示给用户与拿结果训练本地模型是两件事，后者不进入本项目默认流程。[用户协议](https://docs.bigmodel.cn/cn/terms/user-agreement)

**接入结论：** 值得首先做 BYOK 视觉标签验证；先用公开、授权、非敏感素材。未核清具体数据处理条款前，不将私人相册、人物原照或实验室未公开数据纳入该免费通道。

### 3.2 阿里云百炼 Qwen-VL：北京地域限时试用

- 官方价格表的北京地域 `qwen3-vl-flash`、`qwen3-vl-plus` 列有各 100 万 Token 免费额度；这类视觉理解模型支持图像输入。额度包含具体型号与有效期条件，不是“永久每月 100 万”。[模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)、[视觉理解](https://help.aliyun.com/zh/model-studio/vision)
- 新人免费额度一般为 90 天，自开通平台、模型发布或申请通过的较晚时间起算；仅北京地域享有该免费额度。已有老账号是否仍有余量，必须看控制台，不能由本项目推断。[新人免费额度](https://help.aliyun.com/zh/model-studio/new-free-quota)
- **已认证用户额度用尽后可能自动转按量付费。** 零预算必须在对应模型详情启用“免费额度用完即停”，并在本软件设置独立到期截止；到期后不继续试探调用。开关支持范围和到期行为接入时逐项验证。[免费规则与停止开关](https://help.aliyun.com/zh/model-studio/new-free-quota)
- 官方对按量付费 API 的数据不用于训练作出说明，Token Plan 个人版/Coding Plan 的条款不同。接入使用普通模型 API；免费抵扣期间适用条款、日志留存和具体地域再核对，不能套用其他套餐承诺。[产品 FAQ](https://help.aliyun.com/zh/model-studio/what-is-model-studio)

**接入结论：** 可作限时质量对照与个人试用，不承担长期免费功能承诺。即使账上还有余额，只要免费权益无法确认，本软件的零预算模式也停止该路线。

### 3.3 Gemini Developer API：有免费图像输入，但不作为大陆默认

- 以 `gemini-2.5-flash-lite` 为核验样本：官方 Standard 价格表明确文本/图像/视频输入及文本输出有免费层。它是视觉理解候选，不能据此推导图像生成也免费。[API 价格](https://ai.google.dev/gemini-api/docs/pricing)
- 免费层受项目级速率和额度限制，应查询 AI Studio 中该项目的实际限制；多个 API Key 不能当作独立免费额度池。不要把联网搜索工具的 RPD 数字当作普通看图请求数。[速率限制](https://ai.google.dev/gemini-api/docs/rate-limits)
- 官方支持地区清单未列中国大陆；服务条款要求服务和 API 客户端面向支持地区，向 EEA、瑞士、英国用户提供 API 客户端时要求使用付费服务。海外服务器不能自动解决最终用户地域资格。[支持地区](https://ai.google.dev/gemini-api/docs/available-regions)、[服务条款](https://ai.google.dev/gemini-api/terms)
- 通常免费服务的输入输出会用于产品改进，人工审核者可能处理内容；条款要求不要提交敏感、机密或个人信息，并存在 EEA 等地域数据条款例外。不能只写“图片不公开”就表示没有数据处理风险。[服务条款](https://ai.google.dev/gemini-api/terms)

**接入结论：** 仅列入符合支持地区与条款的用户可选项，首版大陆方案不依赖它。只支持免费资格已确认的项目，不为了数据条款或更高额度自动绑定账单。

### 3.4 SiliconFlow：视觉可调用，但当前免费资格待确认

- 官方支持多模态图像输入，Qwen3-VL 等属于视觉理解系列；能力文档也要求以模型广场的实际可用清单为准。支持看图不意味着该型号免费。[多模态输入](https://docs.siliconflow.cn/docs/userguide/capabilities/multimodal-vision)
- 不能沿用旧文章的免费模型：官方更新公告明确 `THUDM/GLM-4.1V-9B-Thinking` 于 2026-05-15 下线；公告同时说明从该日起未实名账户限制平台功能。[模型与账户调整公告](https://docs.siliconflow.cn/docs/release-notes/overview)
- 本次未从现行公开资料确认一个可默认启用的长期免费视觉型号；不承诺“注册送 14 元”对所有新账号仍有效。代金券的金额、范围和到期时间以用户实际权益为准，缺少证据时禁用免费路由。[模型中心](https://www.siliconflow.cn/models)、[更新公告](https://docs.siliconflow.cn/docs/release-notes/overview)
- 国内平台隐私政策说明业务输入输出仅短时用于推理，不用于预训练、微调或其他商业目的；另会处理调用日志和安全审核信息。不要把业务数据政策扩大成“任何数据都不保存”。国际站条款须另查。[国内隐私政策](https://docs.siliconflow.cn/docs/legals/privacy-policy)

**接入结论：** 保留适配器规划，状态标记“视觉支持已确认／当前免费资格待核实”。没有明确免费型号或可用试用权益时，不进入零预算模型池。

## 4. 模型能力与许可登记

本地路线仍按现有模块规划评测：轻量图像处理走 CPU；视觉语言模型按需加载；试衣与分割模型单独运行。8GB 显存不能同时常驻试衣模型、VLM 和其他 GPU 模型；量化权重文件大小也不等于实际显存占用。

每个本地或云候选应有一条登记记录：

| 字段 | 必须记录的内容 |
| --- | --- |
| 身份 | 来源、精确模型 ID、代码/权重版本、下载校验值；云模型记录实际返回 ID |
| 能力 | 图像输入、文本输出、图像生成、分割、嵌入分别声明，禁止只写“多模态” |
| 资源 | 本地冷/热启动、峰值显存与内存、输入尺寸；API 记录延迟和请求限制 |
| 许可 | 代码、权重、基础模型、辅助模型、素材分别核对；商用和再分发分别记录 |
| 成本 | 免费型号或试用权益证据、到期日、计费单位、禁止的付费附加功能 |
| 数据 | 提供商、处理地域、训练/保留条款、允许的数据类型、用户授权范围 |
| 状态 | 待核验、已验证、可内测、可发布、过期停用；不以“下载成功”代替可发布 |

软件免费分发也可能是面向公众的产品分发；研究用途权重不能自动进入商店安装包。试衣路线的商用、权重再分发与模型附属组件许可由试衣文档的发布门槛统一控制。

## 5. 路由规则与零预算防线

### 5.1 一次任务如何选择执行位置

1. 检查任务类型、输入用途与隐私模式；实验室数值计算、文件操作、哈希等走确定性本地代码。
2. 有合格本地模型且资源可用时，本地执行；GPU 忙时进入队列，不自动上传图片换速度。
3. 无本地能力或用户主动选云增强时，先检查服务商是否已配置、型号是否允许、免费权益是否有效、数据是否允许外发。
4. 发送前显示服务商、图片范围、用途与免费状态；用户对该任务或明确范围的授权有效，不使用含糊的总开关放行全相册。
5. 免费资格未知、额度到期、超额或服务不可用时，回退合格本地路线；本地也不可用时保留任务输入并提示待配置。
6. 云端结果标注来源、时间、模型和生成标签；不能伪装成本地结果或自动覆盖用户确认过的数据。

### 5.2 默认配置与停止条件

| 配置 | 零预算默认值/规则 |
| --- | --- |
| 云能力总开关 | 关闭；用户自行启用某个提供商 |
| 付费调用 | `allow_paid=false`；日/月付费预算均为 0 |
| 免费模型白名单 | 精确匹配已核验 ID；拒绝 `auto`、未核验别名及自动升级到付费模型 |
| 试用额度 | 保存到期时间和最近确认时间；到期即禁用，不以小额试调用探测 |
| 请求上限 | 初始每个账户/提供商并发 1；输出长度、图片数量、分辨率与超时设上限 |
| 附加功能 | 联网搜索、文件长期缓存、批量服务、工具调用等单独核价；默认不开启 |
| 失败重试 | 429/明确未受理的暂时错误退避后有限重试；不循环切换模型或服务商 |
| 计费状态不明 | 超时后可能已经完成计费，记录为状态待确认；不无条件重新提交 |
| 价格/服务变化 | 清单附核验时间及到期策略；确认改为付费或模型被替换时立即停用 |

本软件的计数是辅助保护，不能代替服务商账单；同一个 Key 在其他软件调用会消耗共同额度。试用 API 必须有服务商侧的免费用尽停止保障；没有可验证保障时，零预算模式仅允许明确免费的型号或完全本地运行。

免费白名单也不能保证供应商永远不改价。因此首发不开放开发者统一担保的“无限免费云增强”，每次发布复核、服务变化时撤销资格；不为了省钱注册/轮换多个账户规避服务商限额。

## 6. 密钥与图片处理

BYOK 密钥通过桌面主进程或本地服务读取，保存在 Windows 系统凭据保护机制中；不存入界面代码、普通 JSON、SQLite 明文字段、日志、崩溃报告或云同步。界面只显示掩码、所属服务与最后验证时间，支持删除和更换。

不要在安装包、WebView 脚本或 Python 程序中硬编码开发者共享 Key。需要公共体验额度时，Key 留在服务器；客户端只能调用受身份、能力、次数和预算限制的业务接口，不能获得任意模型代理权限。

图片外发只准备必要副本：移除定位等不必要 EXIF，按任务压缩，必要时由用户裁切。上传副本不覆盖原始科学图；科学测量始终依据本地原始数据。私人人像默认留在本地试衣流程中。

设备相册的自动分类默认只用本地模型，不允许后台把整套图库分批发送到“免费”视觉 API。云增强只接受用户当次选中的单张或小批次，并且安全类别清单不包含人脸身份、健康、证件、财务、聊天文本或精确位置。免费 API 是否可用不会影响未分类图库、手动分类和本地索引。

BYOK 优先由客户端直连提供商，不要求经过开发者服务器；这可减少带宽和服务器处理的数据。提供商支持直接图片数据时不另建公开图床；只有确需 URL 时才设计受限、短时有效的下载链接。

日志只记任务 ID、提供商、型号、耗时、用量、错误和策略决定，不记完整提示中的个人资料、Base64 图片、密钥或带授权参数的 URL。缓存按本地用户和输入版本隔离；删除素材时删除相应缓存和衍生内容。

## 7. 成本账本与资源预算

| 项目 | 首期策略 | 需要记录的数字 |
| --- | --- | --- |
| 新设备 | 先用现有机器 | 是否真的出现内存/显存瓶颈，升级收益另评估 |
| 模型 API | 免费理解可选，付费预算 0 | 请求数、图片数、Token、权益到期、失败与重试数 |
| 本地推理 | 单 GPU 任务；按需卸载 | 峰值资源、等待时间、每张成功结果耗时 |
| 电力 | 使用整机功耗做估算 | 功率×运行小时×实际电价，不把 GPU 功率当整机功率 |
| 磁盘 | 按模块下载权重，设置缓存容量 | 模型/运行库/原图/结果分别统计，下载前检查余量 |
| 辅助服务器 | 可选，暂不作为本地功能前置 | 实际实例报价、流量、磁盘、快照、域名等 |
| 软件分发 | 安装包与模型包分开规划 | 下载流量、包体、更新下载、签名/商店要求的实际支出 |

`每个可接受结果成本 = 该批次实际总支出 / 人工判定可接受的结果数`；失败生成、模型切换和重试必须计入。免费调用的节省，也要与速度、正确率和隐私要求一起比较。

对 4 核／2GB 辅助服务器，避免整张图片 Base64 在多个进程反复复制、默认全相册同步、独立向量数据库和 GPU 服务。先做小文件/流式上传、体积上限和并发限制的验证，再开放任何图片中转。

## 8. 开发阶段与验收

| 顺序 | 交付物 | 验收方式 |
| --- | --- | --- |
| A 本地基线 | 模型登记、统一资源调度、结果来源记录 | 权重已准备后断网完成已支持流程；无隐式云请求 |
| B 一个免费提供商 | BigModel BYOK 适配器、精确白名单、系统密钥存储 | 后续获授权后用公开测试图验证真实图像输入、中文结构化输出和用量 |
| C 路由与故障 | 免费失效停止、本地回退、取消与错误状态 | 模拟额度耗尽、过期、429、超时、模型下线；付费型号请求被本地拒绝 |
| D 对照评测 | 本地与 API 使用同一组授权样本比较 | 标签正确率、拒答/错误率、响应耗时与资源记录；不是只挑成功案例 |
| E 发布前复核 | 条款/价格复核日期、能力说明、网络披露 | 安装包无共享密钥；用户未启用云时图片不外发；免费失效不使相册等基础功能失效 |

初期 API 评测可用约 50 张授权非敏感图片，覆盖普通服装、植物和日常物体；验收指标随模块范围冻结。精确试衣和实验室分割仍使用各自专门测试集，不把通用 API 的口头认可当成质量证明。

若免费 API 的效果不足，就保留本地功能并显示能力范围；若效果更好，再作为明确可选项。任何付费兜底、云 GPU、公众共享额度或商业授权采购，均需单独成本方案，不由程序在运行时替用户作出消费决定。
